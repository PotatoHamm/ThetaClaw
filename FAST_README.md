# ThetaClaw

ThetaClaw is an OpenClaw-based project focused on securing the execution
environment of personal AI assistants. It aims to preserve OpenClaw's assistant
capabilities while developing a new security architecture for AI agents.

## Project status

Security architecture details, the list of new features, and ThetaClaw-specific
installation, deployment, and usage guides are being prepared.
